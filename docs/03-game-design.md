# 03 — 游戏设计文档 (GDD)

## 1. 核心玩法

植物大战僵尸是一款 **2D 横版塔防游戏**。玩家在 9×5 的草坪上种植植物，抵御从右侧入侵的僵尸，保护左侧的房屋。

### 核心循环

```
收集阳光 → 选择植物卡牌 → 放置植物 → 植物自动攻击 → 僵尸波次推进 → 胜利/失败
    ↑                                                              │
    └────────────────── 下一关 / 重试 ←────────────────────────────┘
```

## 3. 植物详细设计

### 3.1 攻击型植物

```
PeaShooter (豌豆射手)
├── 射程: 整行
├── 攻速: 1.5s/发
├── 伤害: 20
├── 子弹: PeaBullet (直线飞行)
└── 特殊: 无

SnowPea (寒冰射手)
├── 继承自 PeaShooter
├── 子弹: SnowPeaBullet
└── 特殊: 命中附加 Slow (50%移速, 持续3s)

Repeater (双发射手)
├── 继承自 PeaShooter
└── 特殊: 每次射击发射2颗子弹 (间隔0.1s)

Threepeater (三线射手)
├── 同时攻击 3 行 (row-1, row, row+1)
└── 特殊: 每行1颗子弹

Chomper (食人花)
├── 射程: 前方 1.5 格
├── 伤害: 秒杀 (吞咽)
└── 冷却: 咀嚼 42s 后吐出

CherryBomb (樱桃炸弹)
├── 范围: 3×3 格
├── 伤害: 1800 (秒杀范围内所有僵尸)
└── 特性: 放置后 1s 爆炸，植物消失

Jalapeno (辣椒)
├── 范围: 整行
├── 伤害: 1800
└── 特性: 瞬间释放，植物消失

PotatoMine (土豆地雷)
├── 放置后 15s 激活
├── 激活前: 无碰撞体积
├── 激活后: 僵尸踩踏引爆，3×3 范围 1800 伤害
└── 特性: 一次性

Squash (窝瓜)
├── 范围: 前方 1 格
├── 伤害: 1800
└── 特性: 瞄准最近僵尸，碾压后消失
```

### 3.2 防御型植物

```
WallNut (坚果墙)
├── HP: 4000
├── 外观变化: 100% → 66% → 33% (裂纹递增)
└── 特殊: 无攻击能力

TallNut (高坚果)
├── HP: 8000
├── 特殊: 可阻挡 PoleVaulting/Balloon 跳跃
└── 外观: 同 WallNut 三阶段
```

### 3.3 辅助型植物

```
Torchwood (火炬树桩)
├── 效果: 穿过它的豌豆变为 FirePeaBullet
├── FirePea: 伤害×2, 解除冰冻效果
└── 无独立攻击能力

Spikeweed (地刺)
├── 伤害: 20/s 对踩踏僵尸
├── 特殊: 无视僵尸护甲 (直接扣本体 HP)
└── 免疫啃食
```

## 4. 僵尸详细设计

### 4.1 属性表

| 僵尸 | HP | 移速(px/s) | 攻击力(HP/s) | 特殊 |
|------|-----|-----------|-------------|------|
| 普通僵尸 | 200 | 25 | 100 | 无 |
| 路障僵尸 | 560 | 25 | 100 | 路障吸收 360 HP |
| 铁桶僵尸 | 1300 | 25 | 100 | 铁桶吸收 1100 HP |
| 旗帜僵尸 | 200 | 35 | 100 | 标记波次开始，加速同波僵尸 |
| 撑杆僵尸 | 500 | 60→25 | 100 | 跳跃越过第一株植物 |
| 读报僵尸 | 340 | 25→80 | 100→150 | 报纸损毁后狂暴 |
| 橄榄球僵尸 | 1680 | 45 | 150 | 全游戏最快最肉 |
| 舞王僵尸 | 500 | 16 | 100 | 召唤伴舞 ×4 |
| 伴舞僵尸 | 200 | 50 | 100 | 被召唤 |
| 潜水僵尸 | 200 | 25 | 100 | 水中潜行（泳池） |
| 冰车僵尸 | 1400 | 30 | 碾压 | 碾压植物，铺冰道 |
| 气球僵尸 | 200 | 40 | 100 | 飞行，免疫地面攻击 |
| 巨人 | 3600 | 18 | 150 | BOSS，HP<50% 投掷小鬼 |
| 小鬼 | 200 | 50 | 100 | 被巨人投掷，越过防线 |

### 4.2 僵尸状态机

```
WALK ──遇到植物（碰撞检测）──▶ ATTACK ──HP≤0──▶ DEATH
  ▲                              │
  └──── 植物被摧毁 ──────────────┘

WALK/ATTACK 状态下可叠加:
  - FROZEN:  移速×0.5, 攻速×0.5, 蓝色着色, 3s
  - BURNING: 持续伤害, 数值=FirePea.damage/s, 效果持续
```

### 4.3 特殊机制

- **报纸僵尸：** HP 归零时报纸销毁 → 停顿 1s → 狂暴（移速+攻速翻倍）
- **撑杆僵尸：** 检测前方第一株植物 → 跳跃动画 → 落点 = plant.col + 1
- **巨人：** HP < 50% 时停止移动 → 投掷小鬼动画 → 小鬼落在 col 3-5
- **舞王僵尸：** 停止移动 → 踢腿动画 → 上下左右各召唤 1 只伴舞

## 5. 关卡设计

### 5.1 场景类型

| 场景 | 背景 | 行数 | 特殊规则 |
|------|------|------|----------|
| 白天 | 草地 | 5 | 自然阳光掉落 |
| 夜晚 | 草地(夜) | 5 | 无自然阳光，蘑菇系不受夜影响 |
| 泳池 | 泳池 | 6 | 中间 2 行需睡莲种植 |
| 浓雾 | 泳池+雾 | 6 | 视野受限，需灯笼草/三叶草 |
| 屋顶 | 屋顶 | 5 | 需花盆种植，倾斜弹道 |

### 5.2 关卡 JSON 结构

```json
{
  "level_id": 1,
  "name": "白天 — 第一关",
  "background": "day",
  "init_sun": 50,
  "plant_cards": [
    "sunflower",
    "peashooter",
    "wallnut",
    "cherrybomb",
    "potatomine"
  ],
  "waves": [
    {
      "wave_id": 1,
      "announce": false,
      "zombies": [
        {"time": 5000,  "type": "normal",    "row": 0},
        {"time": 10000, "type": "normal",    "row": 2},
        {"time": 15000, "type": "normal",    "row": 4}
      ]
    },
    {
      "wave_id": 2,
      "announce": true,
      "announce_text": "一大波僵尸正在逼近！",
      "zombies": [
        {"time": 60000, "type": "normal",    "row": 1, "count": 3, "interval": 3000},
        {"time": 60000, "type": "conehead",  "row": 3},
        {"time": 75000, "type": "flag",      "row": 2}
      ]
    }
  ],
  "win_condition": "all_zombies_dead"
}
```

**字段说明：**
- `time`：相对波次开始时间的 spawn 时刻（ms）
- `count` + `interval`：批量生成（同一行每隔 interval 出一个，共 count 个）
- `announce`：是否显示"一大波僵尸"警告
- `row`：-1 表示随机行

## 6. 胜负条件

### 胜利
- 关卡中所有僵尸被消灭
- 最后一波僵尸死亡后 5s 判定胜利（防止残余）

### 失败
- 任意僵尸到达房屋线（col 0 左侧阈值）
- 割草机全部触发后，再有僵尸越过
