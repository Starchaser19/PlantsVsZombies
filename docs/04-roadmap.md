# 04 — 实现路线图

## 阶段总览

```
Phase 1 ──▶ Phase 2 ──▶ Phase 3 ──▶ Phase 4 ──▶ Phase 5
(骨架)     (核心)     (扩展)     (润色)     (超越)
1-2天      3-5天      3-5天      2-3天      可选
```

---

## Phase 1: 项目骨架 ▸ 预计 1-2 天

**目标：** 空白窗口能跑起来，状态机可切换，草坪可见

### 任务清单

| # | 任务 | 产出 | 验证方式 |
|---|------|------|----------|
| 1.1 | 初始化项目结构 | 目录树 + `requirements.txt` + `pyproject.toml` | `tree` 命令检查 |
| 1.2 | `main.py` 骨架 | Pygame 窗口 + 60fps 主循环 + 退出逻辑 | 运行看到黑窗口 |
| 1.3 | 状态机框架 | `GameState` 抽象基类 + `StateMachine` 栈管理 | 单元测试：push/pop/change |
| 1.4 | MenuState 占位 | 点击"开始游戏"→ push LevelState | 点击后屏幕切换 |
| 1.5 | LevelState 占位 | `update()` + `draw()` 空循环 | 打印 "LevelState active" |
| 1.6 | 网格地图渲染 | 9×5 绿色网格 + 背景色块 | 看到棋盘格 |
| 1.7 | 坐标转换 | `screen_to_grid()` + `grid_to_screen()` | 单元测试全覆盖 |
| 1.8 | 鼠标事件 | 点击网格输出 `(col, row)` | 控制台打印坐标 |

### 产出截图（预期）

```
黑色背景 + 绿色网格 + 点击输出坐标到控制台
```

## Phase 2: 核心玩法 ▸ 预计 3-5 天

**目标：** 最小可玩原型 — 向日葵 + 豌豆射手 vs 普通僵尸

### 任务清单

| # | 任务 | 详情 |
|---|------|------|
| 2.1 | **GameObject 基类** | `rect`, `image`, `hp`, `alive`, `update(dt)`, `draw(screen)`, `take_damage(n)` |
| 2.2 | **Plant 基类** | 继承 GameObject + `sun_cost` + `cooldown` + 占位色块渲染 |
| 2.3 | **SunFlower** | 每 24s 产出一个 Sun 实体 |
| 2.4 | **PeaShooter** | 每 1.5s 向右发射 Bullet |
| 2.5 | **Zombie 基类** | 继承 GameObject + WALK/ATTACK/DEATH 状态机 + 占位色块 |
| 2.6 | **NormalZombie** | 25px/s 移速，遇到植物切换 ATTACK |
| 2.7 | **Bullet 系统** | PeaBullet 直线飞行 + 命中僵尸扣血 + 飞出屏幕销毁 |
| 2.8 | **Sun 系统** | 自然掉落(每10s) + 向日葵产出(每24s) + 鼠标点击收集 |
| 2.9 | **CardPanel** | 植物卡片展示 + 点击选中 + 冷却遮罩 + 阳光不足提示 |
| 2.10 | **种植流程** | 选卡 → 鼠标半透明预览 → 点击网格种植 → 扣阳光 |
| 2.11 | **碰撞检测** | Bullet×Zombie (rect 碰撞) + Zombie×Plant (攻击触发) |
| 2.12 | **胜负判定** | 全部僵尸死→胜利 / 僵尸过线→失败 |

### 里程碑验证

```
☑ 开局有 50 阳光
☑ 能选向日葵并种下
☑ 向日葵产出阳光，可点击收集
☑ 能选豌豆射手并种下
☑ 豌豆自动射击，命中僵尸扣血
☑ 僵尸死亡后判定胜利
☑ 僵尸到达左侧后判定失败
```

## Phase 3: 内容扩展 ▸ 预计 3-5 天

**目标：** 完整的植物/僵尸阵容 + 关卡系统

### 任务清单

| # | 任务 | 详情 |
|---|------|------|
| 3.1 | **更多植物** | WallNut, CherryBomb, SnowPea, PotatoMine, Repeater, Chomper, Squash, Spikeweed, Torchwood |
| 3.2 | **更多僵尸** | Conehead, Buckethead, FlagZombie, PoleVaulting, Newspaper, Football |
| 3.3 | **关卡系统** | JSON 驱动，`data/levels/level_01.json` → `WaveManager` 解析 |
| 3.4 | **WaveManager** | 按时间线 spawn + 批量生成 + 波次警告文字 |
| 3.5 | **LawnMower** | 每行一个，僵尸触发后碾压整行 |
| 3.6 | **MenuBar** | 顶部栏：阳光计数 + 进度条 + 暂停按钮 |
| 3.7 | **Shovel** | 铲子工具：点击铲子→点击植物→铲除（返还50%阳光？） |
| 3.8 | **GameOver 界面** | 胜利/失败画面 + 统计数据 + 重试/下一关按钮 |
| 3.9 | **关卡选择** | MenuState 加关卡列表，可解锁推进 |
| 3.10 | **植物属性 JSON** | `plants.json` 外部化所有植物参数 |

### 里程碑验证

```
☑ 8+ 种植物可用
☑ 5+ 种僵尸类型
☑ 3 个可玩关卡，难度递增
☑ 波次警告 + 割草机
☑ 完整游戏循环：选关→游玩→结算→下一关
```

## Phase 4: 润色 ▸ 预计 2-3 天

**目标：** 从"功能完整"到"体验优秀"

### 任务清单

| # | 任务 | 详情 |
|---|------|------|
| 4.1 | **动画系统** | 帧循环动画框架 + 植物待机动画 + 僵尸行走动画 |
| 4.2 | **特效** | 豌豆命中粒子、爆炸动画、冰冻闪烁、阳光收集飘字 |
| 4.3 | **音效** | 射击、爆炸、收集阳光、僵尸呻吟、BGM |
| 4.4 | **主菜单美化** | 标题画面 + 开始按钮 + 动画背景 |
| 4.5 | **暂停菜单** | ESC 暂停/继续 + 重新开始 + 返回主菜单 |
| 4.6 | **过渡动画** | 关卡切换淡入淡出 |
| 4.7 | **Tutorial** | 第一关增加引导提示（"点击阳光收集"、"拖动植物放置"） |
| 4.8 | **性能优化** | 对象池 + 脏矩形渲染 + 性能测试 |

### 里程碑验证

```

☑ 流畅的动画和过渡
```

## 开发节奏建议

```
Week 1: Phase 1 + Phase 2 前半（种下第一颗豌豆）
Week 2: Phase 2 完成（最小可玩原型跑通）
Week 3: Phase 3 前半（植物阵容 5+）
Week 4: Phase 3 完成（3 关可玩）
Week 5: Phase 4 前半（动画 + 音效）
Week 6: Phase 4 完成（可发布 alpha 版）
Week 7+: Phase 5 按兴趣选做
```

## 测试策略

| 层级 | 工具 | 覆盖目标 |
|------|------|----------|
| 单元测试 | pytest | 坐标转换、碰撞检测、计时器、JSON 解析 |
| 集成测试 | pytest + pygame headless | 植物-僵尸交互、波次管理、阳光经济 |
| 手动测试 | 游玩 | UI 体验、手感、平衡性 |
| 性能测试 | cProfile | 60fps 稳定性，内存泄漏检测 |
